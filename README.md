# Lebah Madu

1. Edit `app/src/main/java/com/lebahmadu/app/AppConfig.kt` (CONFIG_URL, WEB_URL).
2. Put `config.json` in your GitHub repo:
   {"login_enabled": true, "codes": ["HONEY-1234", "HONEY-5678"]}
3. Open the folder in Android Studio (Ladybug or newer, JDK 17). It generates the Gradle wrapper on sync.
